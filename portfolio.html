CASE 01 · PROCESS DESIGN / AUTOMATION

담당자의 반복 판단을 규칙으로 바꿔
리스트 작성시간을 단축하다

운영 적용
집중입고 리스트 작성 8~10분 → 3분 이내 · 상품 매칭·제외·분류 조건 자동화
문제 정의

담당자가 여러 데이터에서 검품 대상을 확인하고 상품을 매칭·정렬하는 과정에서 누락과 오입력 위험이 발생했습니다.

설계 판단

사람이 매번 확인하는 기준을 ‘상품 매칭 → 예외 제외 → 존·대상 분류 → 출력’의 명시적 규칙으로 분해했습니다.

직접 수행

입고 이력·VOC·검품강화 목록·상품 정보를 연결하고 Google Sheets와 Apps Script로 자동 분류·출력 흐름을 구현했습니다.

확인된 결과

현장 운영에 적용하여 리스트 1회 작성시간을 3분 이내로 단축했습니다. 오류율 감소는 정량 측정 자료가 없어 별도 성과 수치로 제시하지 않습니다.

INPUT입고·VOC·상품정보
RULES매칭·제외·분류
OUTPUT존별 리스트 생성
USE현장 검품 준비
AS-IS · 수동 작성약 8~10분
반복 조회·매칭·복사·정렬
TO-BE · 규칙 기반 자동화3분 이내
일관된 분류·출력 절차로 전환

시각화는 실제 업무 로직을 요약한 도식이며, 내부 데이터와 실제 화면은 공개하지 않았습니다.

CASE 02 · USER WORKFLOW / PILOT

기록 누락 문제를 안내가 아닌
입력 동선 재설계로 해결하려 하다

2주 파일럿 완료
반복 기록 업무 5개를 QR 진입점 하나로 통합 · 현장 피드백을 화면과 기능에 반영
문제 정의

수기 대장 기록이 반복적으로 누락됐고, 기존 안내만으로는 작성 습관을 안정적으로 만들기 어려웠습니다.

설계 판단

사용자가 기억해야 하는 업무를 늘리는 대신 접속과 입력 과정을 단순화했습니다.

직접 수행

QR → Web App → Google Sheets 자동 누적 구조를 설계하고 2주간 파일럿을 운영하며 사용성 피드백을 반영했습니다.

확인된 결과

5개 업무의 진입점을 통합했고 기존보다 편리하다는 사용자 피드백을 확보했습니다. 기록 누락률 감소는 별도 정량 검증이 필요합니다.

ACCESSQR 접속
SELECT기록 업무 선택
INPUTWeb App 작성
STORESheets 자동 누적

향후 보완 가능한 지표: 실제 사용률, 기록 완료율, 누락 건수, 평균 입력시간

CASE 03 · DATA-DRIVEN DECISION

고객 불만 비율과 품질 검증을
운영 종료 판단에 연결하다

운영 반영
거봉 시즌 종료 단축 제안 → 10월 21일 최종 입고 후 종료 반영
문제 정의

시즌 말 거봉에서 선도·맛 관련 VOC와 낱알 탈락이 확인되어 판매 지속에 따른 리스크가 있었습니다.

판단 근거

VOC 발생률과 입고 검품, 판매기한 테스트를 함께 검토했습니다. 3일차 테스트에서 낱알 탈락이 추가 확인됐습니다.

직접 수행

거봉 450g·650g의 시즌 종료 시점 단축을 커머스에 제안했습니다.

확인된 결과

10월 21일 최종 입고 후 시즌 종료가 운영에 반영됐습니다. 종료 후 VOC 감소 효과는 별도 검증 자료가 없습니다.

거봉 450g VOC 발생률 비교
41주 · 17건 / 2,0900.81%
42주 · 16건 / 1,6330.98%

건수는 17→16건으로 줄었지만 발생률은 0.17%p 상승. 막대는 1.00%를 비교 기준으로 표시.

CASE 04 · POLICY DESIGN / QUALITY OPERATIONS

평균값 뒤에 숨은 편차를 분석해
관리 기준의 개선안을 설계하다

파일럿 기준·제안
수박 11 Brix 파일럿 기준 마련 · 사과 SKU별 최소당도 하한 관리방식 제안
수박 · 고객 경험과 기준 연결

단맛 관련 VOC, 측정 당도, 관능평가, 경쟁사 기준을 함께 비교해 11 Brix 검증용 파일럿 기준을 마련했습니다.

11 Brix
검증용 파일럿 기준
사과 · 평균의 한계 보완

평균 당도가 기준을 충족해도 저당도 개체가 섞이는 문제를 SKU별 분포·표준편차·기준 미달률로 검토했습니다.

산출물: SKU별 최소당도 하한 관리방식 제안

두 사례 모두 기준 설계 및 제안 경험이며, 판매 성과나 VOC 개선을 확정 성과로 주장하지 않습니다.

ADDITIONAL IMPROVEMENTS

다른 형태의 운영 문제도 같은 방식으로 접근했습니다.

QC 마감 공유 프로세스

Reminder·Web App으로 공유 흐름을 재설계하여 업무 소요시간을 약 30분에서 15~20분으로 단축했습니다.

표준화

QC 온보딩 가이드 구축

경험에 의존하던 검품·회송 절차를 사원용과 선임·스텝용 통합 가이드로 문서화했습니다.

공정 개선

간편과일 실링 불량 개선

포장 공정에서 실링 터짐 원인을 확인하고 열선 높이를 조정했습니다.

개선 제안

PB 간편과일 판매일수 검증

개선 제안

회송률과 판매기한 테스트에서 확인한 품질 리스크를 근거로 시즌 종료 개선안을 설계했습니다.
